# AI Tools Used

## Tools
- ChatGPT — used to structure the solution, design the agent workflow, draft documentation, and generate/iterate prototype code.
- Streamlit — used to create the clickable local web prototype.

## How AI was used
AI assistance was used for:
1. converting the assignment requirements into an implementation plan;
2. structuring supplied customer/booking/policy information;
3. drafting the conversation and decision flow;
4. implementing the prototype UI and policy guardrails;
5. preparing the architecture, demo script and presentation content.

## Important disclosure
The prototype's policy facts are taken from the supplied assignment data. AI was not used to invent additional airline rules or customer information.

# Inputs, Sources and Assumptions

## Inputs
- Customer profiles supplied in the Assignment 3 data pack.
- Booking and disruption details supplied in the Assignment 3 data pack.
- Service rules and authority limits supplied in the Assignment 3 data pack.
- Customer scenario requests supplied in the Assignment 3 data pack.

## Source policy
The assignment explicitly instructs the student to use only the supplied material and not invent rules, policies or customer information.

## Assumptions
- The prototype treats the supplied booking record as the source of truth for the selected scenario.
- If the supplied material does not provide an alternative flight, the agent does not invent one.
- Requests outside the supplied authority are marked for escalation rather than being promised.
- The prototype is a demonstrator; it does not connect to a real airline reservation system or payment system.
